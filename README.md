# 📈 毎日の株式市場リサーチ

Claude が毎朝（平日 7:43 JST）株式市場を調査し、レポートと学びをここに記録していきます。

- `reports/YYYY-MM-DD.md` … その日のマーケットレポート
- `notes/glossary.md` … 調査中に出てきた用語・概念の勉強ノート（随時追記）
- `notes/themes.md` … 継続して追いかけているテーマ（随時更新）
- `ROUTINE.md` … 毎日の調査手順

> ⚠️ これは学習目的の記録であり、投資助言ではありません。数値はニュースソースによって食い違うことがあるので、売買判断の前には必ず一次情報で確認してください。
